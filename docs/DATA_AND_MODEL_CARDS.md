# Data Documentation and Model Card

**Candid note:** this project trains and uses **no ML model** and has **no training or retrieval dataset**. A full data sheet and model card would be filler, so this file covers only the small parts that count. Revisit if AI bots or LLM narration are added.

## Data card

| Dataset | Content | Source | Cleaning | Bias and risk |
|---|---|---|---|---|
| Role config (`roles.json`) | Role ids, abilities, team, night order | Written by us from common Mafia rules | Reviewed in playtests | Balance varies by group. Make ratios host settings. |
| Narrator lines | Night, morning and death messages, English and Hinglish | Written by us and friends | Manual review | Jokes about real friends can hurt. Add an opt-out and keep it light. |
| Death-story templates | Funny kill messages | Written by us | Manual review | Avoid slurs and real-person attacks |
| Game history (v3 only) | Completed game rows | Generated by play | None | Contains friend names. See `COMPLIANCE.md`. |

## Model card: browser TTS (only AI component, v2)
| Field | Value |
|---|---|
| Model | Browser Web Speech API `speechSynthesis`, or pre-recorded clips |
| Intended use | Read narrator lines aloud |
| Not for | Impersonating real people, anything outside the game |
| Inputs | Short text strings from our narrator file |
| Outputs | Audio on the player's own device |
| Metrics | Subjective: audible, understandable, starts after one user tap |
| Known limits | Voices differ per device. Hinglish and Hindi quality varies. iOS and Chrome need a user tap before speech. |
| Fallback | Text only, or pre-recorded audio files |
| Ethics | No personal data sent to a third party when using the browser API (verify per browser) |
